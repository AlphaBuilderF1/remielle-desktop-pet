蕾米埃尔 AI 桌面宠物 v0.3.0
================================

这是一个非官方同人作品，与《绝区零》及其官方无关，仅供个人学习与娱乐。

开始使用
--------
1. 请先完整解压 ZIP，不要直接在压缩包里运行。
2. 双击“蕾米埃尔桌宠.exe”。
3. 单击角色可以听她说话，双击打开聊天窗口，右键打开功能菜单。
4. 未配置 AI 时也能使用离线陪伴、待机动作和情绪反馈。

接入 AI
-------
右键角色 → 设置 AI，填写兼容接口的地址、模型名称和 API 密钥。
密钥会通过当前 Windows 账户加密后保存，不会以明文写入文件。

本地数据
--------
首次保存设置或进行对话后，程序目录会出现：
- config.json：设置及加密后的 API 密钥
- memory.json：最近对话、长期记忆、情绪与关系状态

升级时可以保留这两个文件。若要完全重置，请先退出桌宠，再删除它们。
请勿将包含个人数据的这两个文件发给其他人。

常见问题
--------
- Windows 提示未知发布者：当前测试版尚未购买代码签名证书。请只从项目官方 GitHub Release 下载，并核对 SHA-256 文件。
- 双击没有反应：把整个目录解压到桌面或文档目录后重试，不要只复制 exe。
- 程序启动失败：查看同目录下自动生成的“启动错误.log”。
- 如何退出：右键角色 → 退出。
